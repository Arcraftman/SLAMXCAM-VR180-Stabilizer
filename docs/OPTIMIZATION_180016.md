# 180016 素材防抖优化

输入：`D:/Video/Slam_20260927_180016_489.mp4` 及同名 `_motion.slamimu`。
6000×3000、308 帧、约 10.265 秒，配套 2253 个陀螺仪样本。
沿用已验证的 2026 横屏传感器映射、逐帧曝光中点和 IMU 滚动快门校正。

## 实测选择

在相同官方 GPU 渲染器、1280×640 预览下，对输出左眼的 90°、640×480 透视视野重新测量顶部背景特征运动。
指标包含旋转、平移视差和跟踪噪声；不能等同于完整双目质量或高频抖动的精确真值。

| 方案 | 位移中位数（像素/帧） | 位移 RMS（像素/帧） |
| --- | --- | --- |
| 原片 | 1.628 | 2.791 |
| 普通 IMU 防抖，1000 ms / 15° | 0.488 | 1.409 |
| 增强平滑，2500 ms / 30° | 0.485 | 1.407 |
| 固定 IMU 视角 | 0.457 | 1.345 |
| 最终受限视觉辅助固定视角 | **0.438** | **1.298** |

仅增加平滑强度几乎没有额外收益。尝试额外时间偏移 +15 ms 在训练前半段改善，但后半段残差变差（0.164° → 0.191°），因此未采用。
直接累积视觉运动虽降低 RMS，却使中位数恶化、产生长期漂移，因此未作为最终方案。

## 最终方法

左右眼分别提供背景特征对应，但仅估计一个共同旋转，并以同一个姿态渲染两眼。不会分别对左右眼施加二维形变。

视觉证据必须满足双目旋转一致性、刚性拟合误差和 IMU 偏差阈值；失败时使用 IMU。307 个帧间间隔中接受了 287 个，双目旋转估计差异中位数约 0.015°。
对融合预测设置 300 ms 回归 IMU 轨迹的时间常数，以及 3° 偏离上限，限制长期漂移，只保留短时残余修正。
固定目标用于本次转动范围较小的素材；大幅转身素材不能照搬该设置，否则可能暴露未拍到的区域。
滚动快门仍使用原始高频 VQF 姿态，而不是从图像插值出行姿态。

最终预览背景运动 RMS 比原普通防抖约低 **8%**，中位数约低 **10%**；相对原片分别约低 54% 和 73%。
这些是本段低分辨率预览的场景指标，不应推广为所有视频的改善比例。平移视差、运动主体和曝光期间形成的模糊仍不能通过一个共同旋转完全消除。
